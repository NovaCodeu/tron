## 🆔 机器唯一标识技术

行业首创的硬件指纹绑定密钥机制——每台设备都拥有全网唯一的机器标识，私钥从出生起就只属于你这台机器。

### 工作原理

1. **① 硬件指纹提取**：程序启动时自动采集本机 CPU 标识、网卡 MAC、磁盘序列号等硬件特征，经 SHA-256 运算生成 128 位机器唯一标识（Machine ID）。每台机器的硬件组合都是独一无二的，因此 Machine ID 全网唯一。
2. **② 加密级随机熵**：采用操作系统级加密安全随机数生成器（CSPRNG）产生 256 位随机熵，与硬件指纹、时间戳进行三层熵源融合，作为私钥派生的种子，确保每一次生成都具备密码学级别的不可预测性。
3. **③ 私钥绑定派生**：最终私钥 = `f(机器标识 ‖ 随机熵 ‖ 时间戳)`。机器标识被永久融合进私钥派生过程：同一目标地址，在你机器上算出的私钥，在任何其他机器上都无法复现。

### 核心优势

- **全网唯一，杜绝撞库**：不同用户、不同设备的私钥空间完全隔离，即使生成相同靓号地址，私钥也互不相同，从源头杜绝"共享私钥"式批量泄露。
- **抗爆破，不可复现**：私钥派生强依赖本机硬件指纹，攻击者无法通过枚举算法或下载开源代码来批量推算你的私钥，爆破成本提升至不可行级别。
- **硬件信息零上传**：机器标识全程在本地生成与使用，硬件指纹信息绝不外传、不存储于任何服务器，在实现私钥唯一性的同时完整保护你的设备隐私。

### 🎯 第三步：两种使用方式

#### 方式一：单地址匹配（推荐新手）

<p align="center">
  <img width="100%" src="/software3.png?raw=true"/>
</p>

**操作步骤：**

1. 在「目标地址」输入框中，输入一个 TRON 地址（以 T 开头的 34 位地址）
   ```
   例如：TG2CMGxnTPgQ6V58kiKd7wbyN8ewtAmY76
   ```

2. 设置匹配规则：
   - **前缀位数**：输入 `2`（表示新生成的地址前2位要和目标地址一样）
   - **后缀位数**：输入 `6`（表示新生成的地址后6位要和目标地址一样）

3. 点击 **「开始生成」** 按钮

4. 等待生成完成，结果会显示在「生成结果」区域

---

#### 方式二：批量规则文件（进阶用户）

**操作步骤：**

1. 创建一个文本文件（如 `rule.txt`），每行写一个目标地址或规则：
   ```
   TTTTTTTTTTZZZZZZZZZZ
   TTTTTTTTTT8888888888
   TG2CMGxnTPgQ6V58kiKd7wbyN8ewtAmY76
   ```

2. 点击「选择文件」按钮，选择你创建的 `rule.txt`

3. 设置匹配规则：
   - **前缀位数**：输入 `0`
   - **后缀位数**：输入 `6` 或 `8`

**示例：**
```
目标地址：TTTTTTTTTT8888888888

前缀0位 + 后缀6位，生成结果：
TGxxxxxxxxxxxxxxxxxxxxxxxxxxxxx888888
↑↑                              ↑↑↑↑↑↑
前0位匹配                        后6位匹配
```

4. 点击 **「开始生成」** 按钮

## 💡 新手必读

### ⭐ 首次使用建议

**强烈建议**第一次使用时按以下设置：

| 参数 | 建议值 | 原因 |
|:----:|:------:|:-----|
| 前缀位数 | `0` | 降低难度，快速出结果 |
| 后缀位数 | `6` | 6位后缀几分钟内可出结果 |
| 生成数量 | `1` | 生成1个就停止 |

**为什么？**
- 后缀位数越高，计算时间越长
- 6位后缀 ≈ 几分钟
- 7位后缀 ≈ 几十分钟
- 8位后缀 ≈ 几小时
- 10位后缀 ≈ 几天

**建议流程：**
1. 先用后缀 6 位测试，确认程序能正常输出
2. 确认正常后，再根据需要提高位数

### 核心密钥派生逻辑（开源代码节选，可逐行审计）

```cpp
// 1. 提取本机硬件指纹，生成机器唯一标识（每台机器不同）
std::string machineId = SHA256(cpuId + macAddr + diskSerial);
// 2. 操作系统级加密安全随机数（CSPRNG，256 位熵）
std::string entropy  = CSPRNG(32);
// 3. 三层熵源融合：机器标识 + 随机熵 + 时间戳 → 私钥种子
std::string seed     = SHA256(machineId + entropy + timestamp);
// 4. 派生 secp256k1 私钥并推导波场地址（全程本地计算，无任何网络调用）
PrivateKey key = secp256k1::fromSeed(seed);
Address    addr = tron::addressFromKey(key);
```

## ❓ 常见问题

<details>
<summary>👉 点击展开常见问题</summary>

### Q1：程序启动后闪退或打不开？
- 检查是否安装了 [Visual C++ Redistributable](https://www.microsoft.com/zh-cn/download/details.aspx?id=48145)
- 检查是否安装了 [NVIDIA显卡驱动](https://www.nvidia.cn/drivers/)
- 确保程序放在英文路径下（路径请勿包含中文、特殊字符及空格。）

### Q2：生成速度很慢或卡住？
- 检查显卡驱动是否最新
- 尝试在 GPU 设备中手动选择独立显卡
- 降低后缀位数，减少计算量

### Q3：集显和独显冲突怎么办？
- 在 GPU 设备下拉框中手动选择独立显卡
- 不要选择"Auto"，直接选择具体的显卡型号

### Q4：如何导入生成的钱包？
1. 打开 TronLink 或其他波场钱包
2. 选择"导入钱包"
3. 选择"私钥导入"
4. 粘贴生成的私钥
5. 完成导入

### Q5：如何验证程序没有后门？
- 建议结合「开源透明 · 可验证安全」区提供的多种方法自行验证：源码审计、SHA-256 校验、VirusTotal 扫描、零联网验证等。验证维度越多，结论越可靠，也欢迎将您的验证结果反馈给我们。

### Q6：为什么不同机器生成的私钥不一样？
- 这是机器唯一标识技术的刻意设计：私钥派生融合了本机硬件指纹，每台机器的私钥空间相互隔离，正是这一特性让私钥无法被他人复现和爆破。

### Q7：算法开源了，别人能算出我的私钥吗？
- 不能。私钥由「机器标识 + 加密随机熵 + 时间戳」三层融合派生，缺少你的机器标识和当时的随机熵，即使拥有全部源码也无法复现你的私钥。

</details>
